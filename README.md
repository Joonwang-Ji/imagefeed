# 이미지피드 (ImageFeed)

여러 검색 소스를 한 번에 검색해서, 여러 곳에서 상위에 뜨는 이미지를 앞에 보여주는 피드형 웹앱입니다.
Cloudflare Workers(무료) 하나로 화면과 서버가 함께 배포됩니다.

## 구조 한눈에

- `public/` : 화면(PWA). 아이폰·아이패드·맥북에서 홈 화면/Dock에 추가해서 앱처럼 사용
- `src/index.js` : 서버. 소스별 검색, 이미지 중계, 암호 확인, 번역(선택)
- `src/filters.js` : 필터 단어 목록과 정상 용어 예외(`SAFE`) (직접 수정 가능)
- `public/color.js` : 이미지 색 분석(대표 색 분류·색 분포·유사도). 색상 필터와 비슷한 이미지 정렬에 씀
- `public/relevance.js` : 검색어와 이미지(제목·태그)의 관련도 점수. 순위 결정과 약한 결과 접기에 씀
- `public/taste.js` : 취향 저장소(기기 안 점수만). `src/season.js` : 기념일·계절 주제(날짜 계산). `src/topics.js` : 뜨는 주제 후보 단어 40개
- `public/safety.js` : 브라우저 AI 점수 + 살색 비율 + 제목·태그 맥락으로 선정성(블러/노골적) 판정
- `tests/` : 자동 점검 파일 (아래 "점검 방법" 참고)
- 북마크는 **각 기기 브라우저 안에만** 저장됩니다. 기기 간 이동은 설정 → 내보내기/가져오기

## 배포 (처음 한 번, 약 15분)

1. **GitHub**: 새 저장소(비공개 추천)를 만들고 이 폴더의 내용을 모두 올립니다.
   (`.dev.vars` 는 올리지 마세요. `.gitignore`가 막아 줍니다.)
2. **Cloudflare 가입** (무료) → 왼쪽 메뉴 **Workers & Pages** → **Create** → **Import a repository** → 방금 만든 저장소 선택 → 설정은 기본값 그대로 **Deploy**.
3. 배포가 끝나면 **Settings → Variables and Secrets** 에서 아래 값을 **Secret** 타입으로 추가합니다.

   | 이름 | 필수 | 설명 |
   |---|---|---|
   | `PASS` | 필수 | 접속 암호. 12자 이상 추천. 지인에게 공유할 암호 |
   | `KAKAO_KEY` | 추천 | 카카오 개발자 → 앱 만들기 → REST API 키 |
   | `NAVER_ID`, `NAVER_SECRET` | 추천 | 네이버 검색 API 키 (아래 주의 참고) |
   | `PIXABAY_KEY` | 추천 | pixabay.com/api/docs 에서 무료 발급 |
   | `UNSPLASH_KEY` | 선택 | unsplash.com/developers 에서 Access Key |
   | `NAVER_BASE` | 선택 | 예전 네이버 개발자센터 키를 쓸 때만 `https://openapi.naver.com/v1/search/image` |
   | `CAPTION_MODEL` | 선택 | AI 이미지 설명에 먼저 쓸 Workers AI 모델 ID. 기본 모델이 안 될 때 바꿔 보세요 |
   | `TR_MODEL` | 선택 | 한글 검색어의 고유명사 판별에 먼저 쓸 Workers AI 텍스트 모델 ID. 기본(`llama-3.1-8b-instruct` → `llama-3.2-3b-instruct`)이 안 될 때 |
   | `TR_SMART` | 선택 | `off` 로 두면 고유명사 판별을 끄고 번역만 씁니다 |
   | `AI_CAPTION` | 선택 | `off` 로 두면 AI 이미지 설명 기능을 끕니다 (무료 사용량 절약) |

   키 없이 바로 동작하는 소스: Openverse, Wikimedia, 시카고 미술관, 클리블랜드 미술관, V&A 박물관, NASA.
   (Met 미술관·미국 의회도서관은 서버 주소를 막아서 제거했고, Pexels는 API 중단으로 제거했습니다.)
   키가 없는 소스(네이버·카카오·Pixabay·Unsplash)는 자동으로 빠집니다. 키를 넣으면 설정 화면의 "키를 등록하면 더 쓸 수 있어요" 목록에서 사라지고 검색에 추가됩니다.
   **Runtime variables and secrets**(Settings 맨 위)에 등록해야 앱에 전달됩니다. Builds 쪽 Variables는 빌드용이라 앱에 전달되지 않습니다.
4. 값을 저장한 뒤 **Deployments → 최신 배포 → Retry/Redeploy** (또는 GitHub에 작은 변경을 올리면 자동 재배포).
5. 주소(`https://imagefeed.○○○.workers.dev`)로 접속 → 암호 입력.
6. 홈 화면에 추가
   - 아이폰/아이패드: Safari → 공유 → **홈 화면에 추가**
   - 맥북: Safari → 파일 → **Dock에 추가**

### 네이버 키 주의
네이버 검색 API는 2026년에 **NAVER API HUB**(네이버 클라우드)로 이전된 문서가 확인됩니다. 새 방식은 `X-NCP-APIGW-API-KEY-ID / KEY` 헤더를 쓰고, 이 앱의 기본값이 그 방식입니다. 키 발급 절차와 조건(결제수단 요구 여부 등)은 제가 확인하지 못했으니, 발급 화면에서 직접 확인해 주세요. 예전 개발자센터 키가 아직 있으면 `NAVER_BASE` 를 위 값으로 설정하세요. 네이버 없이도 카카오 + Pixabay 로 시작할 수 있습니다.

## 기능 요약

- **검색**: 소스 동시 호출 → 관련도 점수로 정렬(아래) → 한 번에 60장씩 보여 주고 [더 보기]로 이어 보기(무한 스크롤 아님), 관련 주제 칩
- **관련도 순위**: 소스가 준 순위만 더하지 않고, 이미지마다 제목·태그가 검색어와 얼마나 맞는지(관련도)를 먼저 따집니다. 등급은 일치(strong)·부분 일치(medium)·판단 불가(unknown, 제목·태그가 없거나 글자 종류가 달라 비교 못 함 — 감점 없음)·한국 검색엔진이라 봐 주는 것(trust)·불일치(weak). 등급 배수 × 소스 가중치 ÷ 소스 순위를 더하며, 여러 소스에 같이 나오면 점수가 합쳐집니다. 한글은 띄어쓰기가 달라도(금강 엑슬루 타워) 맞추고, 긴 복합어는 두 글자 조각 단위로 부분 일치를 셉니다. 번역 전 원문과 영어 번역 중 더 잘 맞는 쪽을 씁니다.
- **약한 결과 접기**: 고유명사나 두 단어 이상의 구체적인 검색어에서, 검색어와 맞지 않는 이미지(예: '금강엑슬루타워' 검색에 나온 금강 강변 사진)는 피드에서 빼고 맨 아래 [관련도 낮은 결과 N개 보기] 뒤에 둡니다. 맞는 이미지가 적으면 "정확히 맞는 이미지는 N개뿐이에요"라고 알려 줍니다. 한 단어짜리 일반 검색어(고양이 등)는 접지 않고 점수순으로만 보여 줍니다. 뷰어의 "비슷한 이미지"도 접지 않습니다.
- **소스별 가중치**: 검색어에 맞춰 바뀝니다. 미술관(시카고·클리블랜드·V&A)은 미술·디자인·공예 검색어일 때만 높이고, NASA는 우주 검색어일 때만 높이며, 한글 검색어면 네이버·카카오를, 고유명사면 위키 저장소를 높입니다. 사용자가 [소스]에서 직접 고른 소스는 그대로 씁니다. 한 소스의 평균 관련도가 낮으면 그 소스의 비중을 줄입니다.
- **[더 보기]**: 받아 온 이미지는 대기열에 모아 점수순으로 60장씩(뷰어는 30장씩) 올립니다. 이미 올라간 카드는 순서가 바뀌지 않습니다. 보여 줄 만한 이미지가 새로 안 나오는 쪽이 연달아 2번이거나 한 번에 6쪽 넘게 불러오면 자동 불러오기를 멈추고 [더 보기]를 기다립니다(엉뚱한 결과만 나오는 검색어에서 요청이 끝없이 나가는 것 방지). 첫 화면은 빠른 소스 결과 12장을 먼저 보여 주고, 모든 소스가 도착하면 나머지를 점수순으로 채웁니다.
- **한글 검색어 자동 번역**: 영어 전용 소스에는 번역본으로 검색 (화면에는 안 보임). 한글 검색어는 Workers AI 텍스트 모델에게 고유명사인지 한 번 더 물어, 고유명사면 뜻풀이 번역 대신 로마자(영어) 이름을 쓰고 위키 저장소는 한글 원문도 함께 검색합니다. 같은 검색어는 7일 캐시되고, 4초 안에 답이 없거나 실패하면 기존 번역만 씁니다.
- **트렌드 탭** (11차 개편): 위에 분류 알약 4개(모두 / 지금 인기 / 베스트 / 에디터 픽), 그 아래 주제 칩 한 줄(이름만, 가로 스크롤), 아래는 이미지 무한 피드입니다. 칩을 누르면 피드가 그 주제로 바뀌고, 한 번 더 누르면 돌아와요. 3쪽쯤 지나면 [더 보기] 버튼이 나오고 누르면 계속됩니다. 서버는 `/api/trends?page=&g=&topic=&pc=` 로 쪽 단위로 줍니다(위키 ‘요즘 화제’는 없앴어요).
  - 지금 인기 = 네이버 뜨는 주제 이미지, 베스트 = Pixabay·Unsplash 인기, 에디터 픽 = Wikimedia Commons 추천 이미지. 취향 학습·블러·추천 안 함 규칙은 그대로 적용됩니다.
  - 🗓 **다가오는 행사·계절**: 대림절 D-30, 수능, 크리스마스처럼 날짜로 계산합니다(외부 호출 없음, `src/season.js`). 음력 행사(설날·부처님오신날·추석)는 표에 직접 적은 2026~2028년 날짜라, 해가 바뀌면 추가해야 해요.
  - 🔥 **뜨는 주제**: 네이버 데이터랩 검색어트렌드로 `src/topics.js` 의 후보 40개 중 최근 7일 검색량이 직전 3주보다 늘어난 순으로 보여 줍니다(▲40%). **네이버 키 + NAVER API HUB 의 ‘검색어트렌드’ 이용 신청**이 필요하고, 안 되면 이유가 안내문에 나옵니다. 12시간 캐시. `TREND_TOPICS=off` 로 끌 수 있어요.
  - **이미지 분류**: 추천 = 인기 사진(Pixabay·Unsplash) + 잘 찍은 사진(위키미디어 커먼즈 우수 사진, 날마다 다른 구간) / 오늘의 화제(위키백과 많이 본 문서 — 사람들의 취향보다 화제성이라 추천에는 섞지 않고 따로 둠). 취향 학습을 켜면 내 취향에 맞는 사진이 위로 옵니다.
  - 공포·선정 제목 제외, 성행위·성기 표현과 AI가 노골적이라 본 이미지는 아예 뺍니다(8차 기준 그대로). 나체 표현은 미술·역사 맥락이 있으면 블러로 남김.
- **색상 필터**: 색을 고르면 기본("정확하게")은 색을 직접 걸러 주는 소스(Pixabay·Unsplash)만 검색해서 빠르고 정확합니다. 필터 패널의 "넓게 (느림)"을 고르면 다른 소스도 쓰되, 이미지를 불러온 뒤 브라우저가 대표 색(가운데·선명한 색에 가중치)을 뽑아 걸러냅니다. 그 소스들은 작은 썸네일로 색만 분석합니다. 색 지원 소스가 하나도 없으면 자동으로 "넓게"와 같게 동작합니다.
- **톤 필터·팔레트**(9차): 필터의 ‘톤’ 줄에서 파스텔·비비드·밝은·차분한·어두운·흑백·따뜻한·차가운을 고릅니다. 이미지를 불러온 뒤 브라우저가 판별해서 걸러요(천천히 채워짐). 뷰어에서는 이미지의 대표 색 5개(색 점)와 톤이 보이고, 색 점을 누르면 그 색 필터로 같은 주제를 다시 찾으며, 비슷한 이미지 머리말의 [같은 톤만]으로 톤이 같은 것만 모아 볼 수 있어요.
- **부분 검색**(9차): 뷰어의 [✂ 부분 검색] → 손가락으로 찾을 영역을 그리고(안에서 끌면 이동) [이 부분으로 찾기]. 그 부분만 잘라 AI가 설명한 말로 비슷한 이미지를 찾습니다(AI 설명을 켜 둔 서버에서만, 잘린 작은 이미지가 Workers AI 로 가요).
- **필터 버튼**: 방향·색상은 "필터" 버튼 안에 모여 있습니다. 필터 초기화 버튼과, 맨 왼쪽 ⌂ 버튼(처음 화면으로 + 필터 초기화)이 있습니다.
- **뷰어**: 이미지를 누르면 크게 보이고, 아래로 스크롤하면 "비슷한 이미지"가 계속 이어집니다(AI 설명 → 태그+색 이름 → 태그 → 제목 키워드 → 현재 검색어 순서로 검색). 불러온 비슷한 이미지는 현재 이미지와 색 분포가 가까운 순으로 한 번 정리됩니다(원래 검색 순서와 반반 반영, 이미지 근처에 있을 때만). 이미지 확대·축소는 뷰어 안에서만: 두 손가락 핀치, 더블탭, 확대 상태에서 끌기, 컴퓨터는 Ctrl+휠. 오른쪽 위 ✕ 와 오른쪽 아래 [✕ 닫기] 버튼, 뒤로 가기로 닫습니다. 비슷한 이미지를 누르면 그 이미지로 들어가고, 뒤로 가기(또는 스와이프 뒤로)로 이전 이미지에 돌아옵니다. 이미지를 빠르게 넘기면 멈춘 뒤(0.4초) 마지막 이미지만 검색하고, 큰 이미지는 썸네일보다 먼저 받습니다.
- **AI 이미지 설명(선택)**: 태그가 3개 미만인 이미지(네이버·카카오 등)는 AI가 한 줄로 설명한 말로 비슷한 이미지를 찾고(연달아 3번 실패하면 10분 쉼), 뷰어의 [AI로 다시 찾기] 버튼으로 직접 시킬 수도 있습니다. 검색창의 📷 로 사진을 올리면 AI가 설명한 말로 검색합니다. 작게 줄인 이미지가 Cloudflare Workers AI 로 전달되고, Workers AI 무료 사용량(번역과 공유)을 쓰며, 같은 이미지는 7일간 저장해 다시 쓰기 때문에 사용량이 줄어듭니다. 설정에서 끌 수 있습니다.
- **홈 추천 주제**: 넓은 카테고리(풍경·인테리어·건축·음식·우주·미술·디자인 등 30여 개, `public/app.js` 의 `CATS`) 중 열 때마다 무작위 10개를 보여 주고, 누르면 세부 주제로 내려갑니다. 북마크·학습한 취향이 있으면 ⭐ 태그가 두세 개 섞입니다(비공개 모드에서는 안 보임). [🔀 다른 주제]로 다시 섞기.

- **비슷한 이미지**(10차): 검색어와 거의 안 맞는 이미지는 [관련도 낮은 결과 보기] 뒤로 접어, 성경·주제와 상관없는 이미지가 섞이는 것을 줄였어요.

- **오프라인**: 서버에 닿지 않으면 저장해 둔 북마크만 열리는 모드로 시작하고, 연결이 돌아오면 [다시 연결](또는 자동)로 일반 모드로 돌아옵니다.

## 필터 동작

- **선정적 이미지**: 기본 블러. ① 검색엔진 자체 필터(Pixabay/Unsplash/Openverse) ② 제목·태그 키워드 ③ 브라우저 안 AI 검사(nsfwjs). 설정에서 블러 해제 가능, 블러된 카드는 탭하면 개별 공개. AI 점수만으로 판단하지 않고 살색 면적과 제목·태그(성경·책·교회 등 평범한 맥락)도 함께 봐서 성경책 위의 손 같은 오탐을 줄였습니다. 그래도 잘못 블러된 이미지는 뷰어의 [블러 해제]로 풀 수 있고(북마크한 이미지는 기억), 북마크는 AI 판정을 저장하지 않고 열 때마다 다시 검사합니다(키워드로 걸린 것만 유지).
- **공포·잔혹**: 선택 불가. 서버가 검색어, 번역된 검색어, 결과 제목/태그를 모두 검사해서 걸러냅니다. 단어 목록은 `src/filters.js`.
- 디자인·사진 용어(노출 콘크리트, 노출 보정, 고어텍스, nude 색상, naked eye 등)는 `SAFE` 목록에 있어서 선정·잔혹으로 잘못 걸리지 않습니다. 필요한 용어를 더하세요.
- 한계: 이미지 자체를 보고 잔혹물을 판별하는 필터는 없어서, 제목/태그에 단서가 없는 잔혹 이미지는 드물게 통과할 수 있습니다. 미술관 소스에는 전쟁·처형 장면이 섞일 수 있어 관련 단어를 필터에 추가해 두었습니다.

## 기록과 개인정보

- 앱은 검색어/조회 기록을 저장하지 않습니다 (주소창에도 안 남음). 저장되는 것은 암호, 설정, 북마크, (켠 경우) 취향 점수뿐입니다. 취향 점수는 ‘단어: 점수’ 모음이라 무엇을 언제 봤는지는 알 수 없어요.

- 이미지는 서버를 거쳐 전달되고(핫링크 차단 회피, AI 검사용), 기기 브라우저에 최대 1시간 캐시됩니다.

## 처음 실행할 때 확인할 것

브라우저 AI 검사(nsfwjs)는 외부 CDN(esm.sh)에서 불러오는 방식이라, 첫 접속 때 동작 여부를 꼭 확인하세요. 못 불러오면 화면에 안내가 뜨고 키워드/검색엔진 필터만 적용됩니다.

- **소스 선택**: 상단 [소스] 버튼을 누르면 소스별 결과 수가 보이고, 소스 이름을 누르면 그 소스에서만 검색합니다(여러 개 선택 가능, [전체 보기]로 해제). 실패한 소스는 ⚠ 로 표시되며 [소스] 버튼 배지로도 알려 줍니다.
- **카카오 화질**: 카카오의 기본 썸네일이 작아서, 원본이 600만 화소 이하이면 원본을 썸네일로 쓰고 실패하면 작은 썸네일로 대체합니다.

- **실제 인기 검색어**: 구글 트렌드(한국) 일일 인기 검색어 RSS를 1시간 캐시로 가져와 트렌드 칩과 ‘인기’ 피드의 주제로 씁니다(`realTrends`, `src/index.js`). 사건·사고·정치·경기 결과·연예인(배우·가수·아이돌 등)·가십(열애·이혼·사과) 뉴스가 붙은 말은 규칙(`NEWSY`)으로 걸러내고, 인물 이름 자체는 한국어 위키백과 분류(살아 있는 사람·출생 연도·배우·가수 등)로 한 번에 묶어 확인해 뺍니다(`personLabels`, 위키를 못 가져오면 건너뜀). Workers AI 가 있으면 ‘이미지로 볼 만한 말’(장소·음식·동물·자연·행사·물건)만 한 번 더 고릅니다. 못 가져오면 기존 방식(데이터랩 후보·계절 주제)으로 채웁니다. 끄기: `REAL_TRENDS=off`, AI 거르기만 끄기: `TREND_AI=off`, 주소 바꾸기: `REAL_TRENDS_URL`.
- **내 취향**: 홈의 ‘내 취향’은 한 주제어 검색이 아니라 트렌드 탭의 ‘내 취향’ 피드로 갑니다. 학습한 취향·북마크에서 자주 나온 말 여러 개(상위 4 + 무작위 2)를 한꺼번에 찾아 번갈아 섞고, 취향 점수로 정렬합니다. ‘모두’에도 일부가 섞입니다. 주제어는 요청 주소로만 가고 서버에 저장하지 않습니다. 비공개 모드에서는 알약이 숨겨집니다.
- ☆ 저장은 **보드 없이** 담고, 알림 옆 [보드 선택] 버튼으로 바로 보드를 고를 수 있습니다(예전의 ‘마지막 보드 자동 사용’ 제거).
