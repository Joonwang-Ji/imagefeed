# 이미지피드 (ImageFeed)

여러 검색 소스를 한 번에 검색해서, 여러 곳에서 상위에 뜨는 이미지를 앞에 보여주는 피드형 웹앱입니다.
Cloudflare Workers(무료) 하나로 화면과 서버가 함께 배포됩니다.

## 구조 한눈에

- `public/` : 화면(PWA). 아이폰·아이패드·맥북에서 홈 화면/Dock에 추가해서 앱처럼 사용
- `src/index.js` : 서버. 소스별 검색, 이미지 중계, 암호 확인, 번역(선택)
- `src/filters.js` : 필터 단어 목록 (직접 수정 가능)
- 북마크는 **각 기기 브라우저 안에만** 저장됩니다. 기기 간 이동은 설정 → 내보내기/가져오기

## 배포 (처음 한 번, 약 15분)

1. **GitHub**: 새 저장소(비공개 추천)를 만들고 이 폴더의 내용을 모두 올립니다.
   (`.dev.vars` 는 올리지 마세요. `.gitignore`가 막아 줍니다.)
2. **Cloudflare 가입** (무료) → 왼쪽 메뉴 **Workers & Pages** → **Create** → **Import a repository** → 방금 만든 저장소 선택 → 설정은 기본값 그대로 **Deploy**.
3. 배포가 끝나면 **Settings → Variables and Secrets** 에서 아래 값을 **Secret** 타입으로 추가합니다.

   | 이름 | 필수 | 설명 |
   |---|---|---|
   | `PASS` | 필수 | 접속 암호. 12자 이상 추천. 지인에게 공유할 암호 |
   | `KAKAO_KEY` | 추천 | 카카오 개발자 → 앱 만들기 → REST API 키 |
   | `NAVER_ID`, `NAVER_SECRET` | 추천 | 네이버 검색 API 키 (아래 주의 참고) |
   | `PIXABAY_KEY` | 추천 | pixabay.com/api/docs 에서 무료 발급 |
   | `UNSPLASH_KEY` | 선택 | unsplash.com/developers 에서 Access Key |
   | `PEXELS_KEY` | 선택 | pexels.com/api 에서 무료 발급 |
   | `NAVER_BASE` | 선택 | 예전 네이버 개발자센터 키를 쓸 때만 `https://openapi.naver.com/v1/search/image` |

   Openverse, Wikimedia 는 키 없이 바로 동작합니다. 키가 없는 소스는 자동으로 빠집니다.
4. 값을 저장한 뒤 **Deployments → 최신 배포 → Retry/Redeploy** (또는 GitHub에 작은 변경을 올리면 자동 재배포).
5. 주소(`https://imagefeed.○○○.workers.dev`)로 접속 → 암호 입력.
6. 홈 화면에 추가
   - 아이폰/아이패드: Safari → 공유 → **홈 화면에 추가**
   - 맥북: Safari → 파일 → **Dock에 추가**

### 네이버 키 주의
네이버 검색 API는 2026년에 **NAVER API HUB**(네이버 클라우드)로 이전된 문서가 확인됩니다. 새 방식은 `X-NCP-APIGW-API-KEY-ID / KEY` 헤더를 쓰고, 이 앱의 기본값이 그 방식입니다. 키 발급 절차와 조건(결제수단 요구 여부 등)은 제가 확인하지 못했으니, 발급 화면에서 직접 확인해 주세요. 예전 개발자센터 키가 아직 있으면 `NAVER_BASE` 를 위 값으로 설정하세요. 네이버 없이도 카카오 + Pixabay 로 시작할 수 있습니다.

## 로컬에서 먼저 써보기 (선택)


## 기능 요약

- **검색**: 소스 동시 호출, 여러 곳에서 상위인 이미지 우선, 무한 스크롤, 관련 주제 칩
- **한글 검색어 자동 번역**: 영어 전용 소스에는 번역본으로 검색 (화면에는 안 보임)
- **트렌드 탭**: 위키백과 "많이 본 문서"를 나라(언어)별로 보여주고, 누르면 이미지 검색. 키 불필요. 사람·사건 위주이며 디자인 유행과는 다릅니다. 공포·선정 제목은 제외됩니다.
- **색상 필터**: Pixabay / Unsplash / Pexels 만 지원. 색을 고르면 이 소스들만 검색합니다(키 필요).
- **방향 필터**: 세로 / 가로 / 정사각. 모든 소스에 적용(일부는 서버에서, 나머지는 화면에서 거름)
- **북마크 + 보드**: 보기 화면의 "보드" 버튼으로 이름을 붙여 묶음. 북마크 탭 위쪽 칩으로 보드별 보기

## 필터 동작

- **선정적 이미지**: 기본 블러. ① 검색엔진 자체 필터(Pixabay/Unsplash/Openverse) ② 제목·태그 키워드 ③ 브라우저 안 AI 검사(nsfwjs). 설정에서 블러 해제 가능, 블러된 카드는 탭하면 개별 공개.
- **공포·잔혹**: 선택 불가. 서버가 검색어, 번역된 검색어, 결과 제목/태그를 모두 검사해서 걸러냅니다. 단어 목록은 `src/filters.js`.
- 한계: 이미지 자체를 보고 잔혹물을 판별하는 필터는 없어서, 제목/태그에 단서가 없는 잔혹 이미지는 드물게 통과할 수 있습니다.

## 기록과 개인정보

- 앱은 검색어/조회 기록을 저장하지 않습니다 (주소창에도 안 남음). 저장되는 것은 암호, 설정, 북마크뿐입니다.
- 검색어는 각 검색 소스(네이버, 카카오 등)로 전달되고, Cloudflare 를 거칩니다. 서버 로그는 꺼 두었습니다(`wrangler.toml`).
- 이미지는 서버를 거쳐 전달되고(핫링크 차단 회피, AI 검사용), 기기 브라우저에 최대 1시간 캐시됩니다.

## 무료 한도 (2026-10 확인 기준, 바뀔 수 있음)

- Cloudflare Workers 무료: 하루 요청 수 한도가 있습니다. 이미지가 서버를 거치므로 소수 지인용으로 적당합니다. 한도에 닿으면 설정에서 "브라우저 AI 검사"를 꺼 직접 로딩하면 요청이 크게 줄어듭니다.
- 네이버 검색 API 하루 25,000회. Brave Search API 는 2026년 2월에 무료 플랜이 없어져 제외했고, DuckDuckGo 는 공식 API가 없어 제외했습니다.
- Unsplash 무료 키는 시간당 호출 수가 적습니다.

## 처음 실행할 때 확인할 것

브라우저 AI 검사(nsfwjs)는 외부 CDN(esm.sh)에서 불러오는 방식이라, 첫 접속 때 동작 여부를 꼭 확인하세요. 못 불러오면 화면에 안내가 뜨고 키워드/검색엔진 필터만 적용됩니다.
