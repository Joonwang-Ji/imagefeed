## 24차에서 바뀐 것
### A. 동기화 합치기 (public/sync.js)
- 원인(23차): 처음 켤 때 기기 값을 v=1 로 올려 **동점**이 되고, 취향·추천 안 함·최근 검색은 값 통째로 "나중에 고친 쪽이 이김"이라 한쪽 단어가 사라짐.
- 이제 **취향/추천 안 함/최근 검색은 충돌 시 합침**(`MERGE`): taste = 단어·색·톤별 최신 점수, mute 합집합(뺀 단어는 tags 에서 제거); avoid = keys 를 키별 최신 시각으로 합집합(최대 600), pref/bad 는 태그별 큰 값; recent = 검색어별 최신 시각, 최신순 30개. 합치기는 순서와 무관·여러 번 해도 같은 결과(키 순서 정렬).
- **충돌 판정**: ① 방금 올린 값을 서버가 안 받았고(r.v ≥ 내 v) 내용이 다름, ② 올릴 변경이 있는데 서버 값이 내가 마지막으로 확인한 버전(`m.rv`)보다 새롭고 내용이 다름. 합칠 값이 있는 키가 올릴 목록에 있으면 **올리기 전에 먼저 받아서**(pre-pull) 합친 뒤 올림(다른 기기 변경을 덮어쓰지 않게).
- 충돌이 아닌 새 값은 그대로 덮어씀 → **지운 단어는 지운 채로 전파**(되살아나지 않음). 합치지 않는 설정(blur, ml, off 등)은 동점/충돌 시 **서버 값이 이김**(기기끼리 서로 뒤집지 않음).
- 합친 결과가 서버 값과 같으면 다시 올리지 않음(핑퐁 없음).

### B. 새로 시작 (한 번만)
- `public/sync.js` 의 `EPOCH = "2026-11-06"`. 동기화 첫 사이클에서 기기의 `m.epoch !== EPOCH` 이면 `resetLocal()`: localStorage 의 `taste`·`avoid`·`recent` 삭제 + 활동 기록(IndexedDB `act`) 비움 + 올릴 목록의 해당 항목 제거 → 화면 갱신. 북마크·보드·메모·설정은 그대로. 동기화를 켜기 전부터 있던 옛 단어도 지워짐(섞여 들어가지 않게).
- 서버 `src/sync.js`: 요청의 `epoch` 가 저장된 값(`sync_items` 의 s='meta', id='epoch')보다 크면 그 계정의 act 와 kv(taste/avoid/recent)를 삭제하고 표지 저장(북마크·설정은 그대로). 표지가 없거나 오래된 기기가 올리는 학습·활동 기록은 **받지 않음**(캐시된 옛 앱이 되살리지 못하게). meta 행은 기기로 보내지 않고 클라이언트가 쓸 수도 없음(`STORES` 에 없음).
- 다음에 또 비워야 하면 `EPOCH` 를 더 큰(나중 날짜) 문자열로 바꾸면 됨.
- 계정별로 따로 적용(지인 계정은 그 계정의 기기가 처음 동기화할 때 한 번).

### C. 설정 화면 (public/index.html, style.css, app.js)
접고 펼 수 있는 6개 묶음(`details.sg`), 제목 오른쪽에 현재 상태 한 줄:
1. **이미지 보호**(펼침): 블러, 브라우저 AI 검사, 안내.
2. **검색 소스**(펼침): 소스를 알약(체크 표시) 토글로, "N/M개 사용", 소스별 설명은 접힘, 키 필요한 소스는 접힌 목록.
3. **맞춤 추천 · AI**: 취향 학습, AI 이미지 설명.
4. **쌓인 단어 · 기록**(접힘): 내 취향 단어·뺀 단어, 추천 안 함 목록, 기록 안내, 지우기 버튼들. 제목 옆에 "취향 N개 · 숨김 N장".
5. **기기 간 동기화**: 켜기, 상태, [지금 동기화], [서버 데이터 지우기].
6. **북마크 · 계정**: 내보내기·가져오기, 암호 다시 입력.
- 긴 설명 문구는 짧게 줄이고 코드가 쓰는 id 는 모두 유지. 소스 체크박스는 진짜 `input` 을 그대로 써서 접근성·기존 동작 유지.

### D. 블러 (public/app.js, style.css)
- 원인: "추천 안 함"으로 걸리는 블러(`.card.avoid`, `avoidBlur`)가 설정과 무관하게 **항상** 걸리도록 만들어져 있었음(CSS 규칙, 뷰어, 카드 탭 3곳).
- 이제 모든 블러가 `body.noblur`(= 설정에서 블러 끔)에서는 걸리지 않음: CSS 규칙에서 `.avoid` 독립 규칙 제거, `applyAvoid` 는 블러 켜짐일 때만 adult/avoidBlur 표시(순위 낮추기는 그대로), 뷰어·카드 탭도 `S.blur` 만 따름. 블러 토글 시 안내 문구도 정확하게("블러를 껐어요…").
- 참고: 선정성 판별로 **결과에서 아예 빼는** 것(트렌드의 노골적 이미지 등)은 블러 설정과 무관하게 그대로.
- 서비스워커 캐시 v25.
