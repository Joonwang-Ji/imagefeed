# 11차 인계 (트렌드 개편 · 홈 칩 · 북마크 관리)

## 변경
- 홈: 추천 주제 칩 2줄 가로 스크롤 → 375×812에서 세 박스가 탭바 위(y=581 < 745)에 들어옴.
- 트렌드: 위키 제거. 분류 모두/지금 인기/베스트/에디터 픽. 주제 칩은 이름만 한 줄. 칩 탭=주제 피드, 재탭=복귀. 무한 스크롤 + 3쪽 뒤 [더 보기]. 서버 페이지네이션(`/api/trends` → items, topics, more, pc, dl). 중복 제거, 취향 학습·블러·off-topic·추천 안 함 유지.
- 카드 길게 누르기 메뉴(480ms): 더 보기/덜 보기(취향 학습 켰을 때만)/추천 안 함/북마크·보드.
- 북마크: 선택 모드(길게 누르기) + 일괄 보드 추가/해제/삭제(삭제는 3초 안에 두 번), 다중 보드(`boards[]`, 옛 `board` 호환), ☆ 짧게=마지막 보드, 길게=보드 시트, 보드 개요 줄(4썸네일, 보드 없음).
- 검색창 placeholder 단축, SW 캐시 v12.

## 검증
- 테스트 10개 전부 통과(server 86 ok, ui 11차 항목 포함).
- Playwright 375px 스크린샷(모의 서버): 홈, 트렌드 전체/주제/더 보기, 카드 메뉴, 북마크 보드 줄, 선택 모드, 보드 시트. 페이지 오류 없음.

## 실기기·실서버 미검증
- 실제 네이버 키로 ‘지금 인기’ 주제 피드와 페이지 이어 받기.
- 아이폰 Safari 길게 누르기 감각(480ms, 이미지 길게 누르기 기본 메뉴와 충돌 여부).
- ☆ 짧게 = 마지막 보드 동작이 의도와 맞는지.
- 기존 북마크(단일 board)의 다중 보드 호환.
