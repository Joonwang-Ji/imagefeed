# 14차 인계 (트렌드 뉴스 필터 정리)
- 배경: 트렌드에 걸리는 필터를 코드로 점검. `NEWSY`(구글 인기 검색어용 뉴스 필터)가 `승`·`골`·`사과`·`사고` 같은 짧은 단어를 포함만 해도 걸러서 골목 카페·골프·골든 리트리버·승마·사과 농장·사고력 퍼즐 등이 빠졌음(샘플로 확인).
- 변경(`src/index.js`):
  - NEWSY 를 분야별(사건·재난 / 수사·재판 / 정치 / 전쟁 / 가십 / 경기 결과 / 금융)로 다시 씀. 한 글자 단어 제거, `사고력`·`폭발적`·`경기도/경기장`·`국회의사당`·`단풍 장관`은 통과.
  - 결정(사용자): 연예·유행 허용(배우·가수·아이돌·감독·선수 단어 제외), 사건·사고·정치·경기 결과·가십(열애·이혼·결별·사과)은 계속 제외.
  - AI 선별 프롬프트: "사람 이름 제외" 삭제 → 연예(드라마·영화·음악·배우·아이돌·밈·챌린지) 포함, 정치·범죄·사고·재난·스포츠 결과·금융·소송·가십·사망 소식 제외.
- 그대로 둔 것: 공포·잔혹(hardBlocked), 선정·노골적, 종교·오컬트(offTopic)는 라벨·뉴스 제목 모두에 계속 적용. 소스 추가는 하지 않음(구글만 유지, 네이버 실검은 2021년 폐지).
- 검증: `tests/server.test.mjs` 에 4개 추가(평범한 단어 통과, 연예 통과, 정치·사고·경기·가십 제외, AI 프롬프트). 예전 코드에서는 4개 모두 실패함을 확인. 이 환경은 구글 RSS 접속이 막혀 실제 데이터는 확인하지 못함.
- 배포 후 확인: 트렌드 칩에 실제 인기 검색어가 나오는지, 연예 항목이 늘었는지, 정치·사건이 섞이지 않는지(섞이면 제목을 알려 주기 → NEWSY 단어 추가).
- 알려진 한계: 연예인 이름 자체(예: 인물 이름만 있는 검색어)는 제목에 사건 단어가 없으면 통과하고, 그 이름으로 네이버·카카오 이미지를 검색하면 기사 사진이 섞일 수 있음. 사건 사진은 단어 필터로 완전히 못 막음.
