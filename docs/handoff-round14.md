# 14차 인계 (트렌드 뉴스 필터 정리)
- 배경: 트렌드에 걸리는 필터를 코드로 점검. `NEWSY`(구글 인기 검색어용 뉴스 필터)가 `승`·`골`·`사과`·`사고` 같은 짧은 단어를 포함만 해도 걸러서 골목 카페·골프·골든 리트리버·승마·사과 농장·사고력 퍼즐 등이 빠졌음(샘플로 확인).
- 변경(`src/index.js`):
  - NEWSY 를 분야별(사건·재난 / 수사·재판 / 정치 / 전쟁 / 가십 / 경기 결과 / 금융)로 다시 씀. 한 글자 단어 제거, `사고력`·`폭발적`·`경기도/경기장`·`국회의사당`·`단풍 장관`은 통과.
  - 1차 결정은 "연예·유행 허용"이었으나 실제로 보니 난잡해서 같은 날 되돌림: 배우·가수·아이돌·감독·선수 단어를 다시 제외(`가수원동`·`감독관`·`선수촌`은 통과), AI 프롬프트도 "사람 이름 제외"로 복원.
  - 신규: 인물 이름 거르기 `personLabels` — 사미자처럼 뉴스 단어가 없는 연예인 이름은 규칙·AI 가 놓쳤음. 키워드를 한국어 위키백과에 한 번에 물어 분류가 사람(살아 있는 사람·○○년 출생·배우·가수 등)이면 제외. 위키를 못 가져오면 건너뜀. AI 프롬프트에도 "이름처럼 보이는 말은 모르는 이름이어도 사람으로 보고 제외" 문장 추가.
- 그대로 둔 것: 공포·잔혹(hardBlocked), 선정·노골적, 종교·오컬트(offTopic)는 라벨·뉴스 제목 모두에 계속 적용. 소스 추가는 하지 않음(구글만 유지, 네이버 실검은 2021년 폐지).
- 검증: `tests/server.test.mjs` 에 4개 추가(평범한 단어 통과, 연예·정치·사고·경기·가십·인물 이름 제외, 위키 실패 시 동작, AI 프롬프트). 예전 코드에서는 4개 모두 실패함을 확인. 이 환경은 구글 RSS 접속이 막혀 실제 데이터는 확인하지 못함.
- 배포 후 확인: 트렌드 칩에 실제 인기 검색어가 나오는지, 연예 항목이 늘었는지, 정치·사건이 섞이지 않는지(섞이면 제목을 알려 주기 → NEWSY 단어 추가).
- 알려진 한계: 한국어 위키백과에 문서가 없는 인물(신인 등)은 못 잡음. 위키 분류 단어(`PERSON_CAT`)로 인물 아닌 문서가 걸리거나(예: 선수·감독이 들어간 분류), 위키 응답 형태가 실제와 다를 수 있음(모의 응답으로만 확인, 이 환경은 위키·구글 접속이 막힘). 사건 사진은 단어 필터로 완전히 못 막음.
