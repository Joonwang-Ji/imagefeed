# 12차 인계
- 👎 덜 보기 제거(카드 메뉴·뷰어) → 추천 안 함에 통합. 이유: 추천 안 함>관심 없어요가 이미 ‘숨김 + 덜 보기’를 포함.
- 전역 user-select/touch-callout 차단 + selectstart/dragstart 방어(입력칸·.selectable 제외).
- 살색 오탐: color.js `vivid()`, safety.js `judge(scores, skin, ctx, other)`. 소품 정물·나무·크리스마스 맥락은 엄격 판정. 실제 nsfwjs 점수로는 이 환경에서 못 돌려 봄 → 실기기에서 문제의 크리스마스 사진 재확인 필요.
- Masonry.balance(): 실측 높이 기준으로 맨 아래 카드를 옮겨 균형(모의 서버: 양쪽 높이 차 70px 이내, 6장 삭제 후 190px 불균형 → 190→ 재정렬 확인).
- 미해결/제안: 트렌드 주제 구성 재검토(사용자 의문). 후보: ‘내 취향’ 칩 우선, 지금 인기 풀을 사용자 관심 주제로 교체.
