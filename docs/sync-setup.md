# 기기 간 동기화 설정 (23차)

코드를 올리기만 하면 앱은 예전처럼 동작합니다. 아래 순서로 Cloudflare 에 저장소를 연결하면 설정 화면의 **[기기 간 동기화]** 가 켜져요.

## 1. D1 데이터베이스 만들기 (필수)
1. Cloudflare 대시보드 → **Storage & Databases → D1 SQL database → Create database**
2. 이름 `imagefeed-sync` → 만든 뒤 화면에 나오는 **Database ID** 를 복사
3. (테이블은 앱이 처음 동기화할 때 자동으로 만들어요. 따로 만들 필요 없음)

## 2. R2 버킷 만들기 (선택: 북마크 썸네일 이미지)
1. 대시보드 → **Storage & Databases → R2 object storage → Create bucket** (처음이면 R2 사용 신청 화면이 나오고 결제 수단 등록을 요구할 수 있어요. 무료 한도 10GB 안에서는 요금이 없어요)
2. 이름 `imagefeed-thumbs`
3. R2 를 쓰지 않으려면 이 단계를 건너뛰세요. 레코드(제목·보드·메모·취향)는 맞춰지고 북마크 이미지는 원본 사이트 주소로 보여요(원본이 사라지면 못 볼 수 있음).

## 3. wrangler.toml 에서 연결
GitHub 저장소의 `wrangler.toml` 맨 아래 주석 블록의 `# ` 를 지우고 ID 를 넣습니다 (웹에서 파일 → 연필 아이콘으로 수정 → Commit).
```toml
[[d1_databases]]
binding = "SYNC_DB"
database_name = "imagefeed-sync"
database_id = "복사한 Database ID"

[[r2_buckets]]
binding = "SYNC_THUMBS"
bucket_name = "imagefeed-thumbs"
```
커밋하면 자동 배포됩니다. (배포가 실패하면 이 블록을 다시 주석 처리하세요. 앱은 그대로 동작해요.)

## 4. 확인
- 아이폰에서 앱을 열고 **설정 → 기기 간 동기화** 가 보이고 체크되어 있는지, [지금 동기화] 후 "마지막 동기화 …" 가 나오는지.
- 다른 기기(아이패드·맥북)에서 같은 암호로 접속 → 북마크가 나타나는지(썸네일은 몇 초 뒤).
- 설정에 "서버 저장소(D1)가 아직 연결되지 않았어요" 가 계속 보이면: 바인딩 이름이 `SYNC_DB` 인지, 배포가 끝났는지 확인.

## 지인 계정 (선택)
Cloudflare → Settings → **Runtime variables and secrets** 에 `PASS_MORE` 를 Secret 으로 추가하고 지인용 암호를 쉼표로 적습니다(예: `abc123,def456`). 그 암호로 접속하면 본인과 완전히 분리된 빈 계정이에요. 암호를 바꾸면 새 계정이 되어 이전 데이터는 보이지 않으니, 바꿀 때는 이전 암호를 `PASS_MORE` 에 남겨 두세요.

## 알아 둘 점
- 한 기기에서 다른 암호로 접속하면, 이 기기에 남은 북마크를 새 계정에 합칠지 물어봅니다. [취소]하면 그 기기에서는 동기화를 끕니다(설정에서 다시 켤 수 있어요).
- 처음 켠 기기는 가진 것을 모두 올리고 서버 것을 받습니다. 같은 항목이면 나중에 고친 쪽이, 설정 값은 서버에 이미 있으면 서버 쪽이 이깁니다.
- 설정 [서버 데이터 지우기]: 이 계정의 서버 데이터·썸네일을 모두 지우고 이 기기의 동기화를 끕니다. 기기 안의 데이터는 그대로예요.
- 무료 한도: D1 하루 쓰기 10만 회·저장 5GB, R2 10GB. 한 사람이 쓰는 양으로는 훨씬 적습니다.
- 서버(Cloudflare 계정 소유자)는 저장된 북마크·활동·취향을 볼 수 있어요. 암호화하지 않습니다.
