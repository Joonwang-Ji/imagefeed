# 이미지피드 — 21차 변경 (2026-10-30)

## 요청
1. 텀블러가 검색에만 쓰이고 홈·트렌드에는 빠져 있어서, 빠진 곳에 모두 추가.
2. 워드프레스(WordPress.com)와 네이버 블로그 소스는 완전히 제거.

## 텀블러를 추가한 곳
- 홈 맞춤 피드: `public/app.js` `FY_SRC` 에 `tumblr` 추가 (한글 관심사는 영어로 번역해 찾음, 한글 검색 가중치 0.4 그대로).
- 트렌드 – 주제 칩: `topicPhotos` 소스에 추가 (번역 대상도 Unsplash 외에 텀블러 포함).
- 트렌드 – 내 취향: `minePhotos` 가 `topicPhotos` 를 쓰므로 포함. 단 **위쪽 3개 주제만** 텀블러 사용.
- 트렌드 – 지금 인기: `hotPhotos` 가 네이버 + 텀블러(**위쪽 2개 주제만**, 영어로 번역해 검색). 네이버가 주력.
- 트렌드 – 베스트: `popularPhotos` 에 텀블러 추가. 텀블러 공개 API 에는 인기순이 없어서 사진 태그(`BEST_TUMBLR_TAGS` 6개)를 날짜·쪽마다 돌려 받은 글 중 반응(`note_count`)이 많은 순으로 고름. 텀블러 항목에 내부용 `notes` 필드를 추가했고 화면으로는 보내지 않음.
- 넣지 않은 곳: 에디터 픽(위키미디어 커먼즈 우수 사진, 선정된 사진 목록이라 텀블러와 성격이 다름).
- 요청 수 보호: 무료 Workers 는 한 요청에서 외부 호출 50회 한도가 있어서(추정) 내 취향 3개·지금 인기 2개로 제한. 유료 플랜이면 `minePhotos` 의 `i >= 3`, `hotPhotos` 의 `slice(0, 2)` 를 늘려도 됨.

## 제거한 것
- `src/index.js`: `naverblog`, `wpcom` 소스, 네이버 블로그용 모바일 주소 변환(`ogTarget`·`MOBILE_UA`). `/api/og` 는 카카오 블로그 뷰어가 쓰므로 유지.
- `public/app.js`: 소스 이름표, 카드가 화면에 오면 대표 이미지를 찾던 `og: "card"` 처리(뷰어의 `og: "view"` 는 유지). `public/relevance.js`: 두 소스의 가중치.
- `wrangler.toml`·README 안내 문구, `tests/blog2.test.mjs` 의 두 소스 관련 검사.
- 환경 변수 `NAVERBLOG`, `WPCOM` 은 이제 아무 영향 없음.

## 검증
- 자동 점검 15개 파일 통과. `tests/server.test.mjs` 에 21차 검사 14개 추가(베스트·주제·내 취향·지금 인기·키 없을 때·홈 소스 목록·제거 확인). 이전 코드에서는 이 중 9개가 실패함을 확인.
- 이 환경은 외부 인터넷이 막혀 텀블러 실제 응답은 모의로만 확인.

## 배포 후 확인
1. 트렌드 베스트에서 텀블러 사진이 섞여 나오는지, 품질·성격이 맞는지(안 맞으면 `BEST_TUMBLR_TAGS` 조정).
2. 홈 맞춤 피드에서 텀블러 사진이 너무 많거나 한글 관심사와 안 맞지 않는지(가중치 조정 가능).
3. 텀블러 태그는 사용자가 붙인 글이라 제목·태그의 선정·공포 단어 필터와 AI 블러에 의존함. 불편한 사진이 보이면 제목과 함께 알려 주기.
4. 서비스워커 v20.
