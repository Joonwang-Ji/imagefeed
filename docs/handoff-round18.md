저장소: https://github.com/Joonwang-Ji/imagefeed (main). 변경 파일을 ZIP(imagefeed-round18.zip)으로 전달 → GitHub 웹에서 같은 경로로 덮어쓰기 업로드(자동 배포).
키: Pixabay, Unsplash, 카카오, 네이버 등록됨. 원칙(바꾸지 말 것): 검색·조회 기록 저장 금지(17차에 완화: 기기 안 활동 기록만), 공포·잔혹 해제 불가, 선정성 기본 블러(설정에서 해제), 사용자는 본인과 소수 지인(성인), 기독교 세계관.

## 신고 내용 (17차 사용 후기)
1. 홈의 ⭐ 칩에 ‘daum카페’가 계속 뜸. 설정에서 지웠는데도 새로고침·앱 재실행 뒤에 그대로. 기록을 모두 지웠을 때는 ‘신혼여행계획’이 ⭐ 로 떴음.
2. 뷰어의 이미지를 전체화면으로 볼 수 있게 해 달라.

## 원인 (코드 기준)
⭐ 칩은 세 곳에서 만들어지는데 설정의 칩 ✕ 는 그중 한 곳(취향 점수 `Taste`)만 지웠습니다.
- 관심사 묶음(`buildInterests`): 이미지 단위 활동 기록(IndexedDB `act`)에서 묶음을 만들고 대표 단어 두 개를 ⭐ 로 보여 줌 → 설정에서 점수를 지워도 활동 기록이 그대로라 같은 묶음이 다시 생김.
- 북마크 단어 대체 칩(`bmTopTags`): 관심사가 하나도 없을 때(예: 기록 모두 지우기 직후) 북마크의 태그·제목 단어를 ⭐ 로 보여 줌 → ‘신혼여행계획’은 북마크에서 온 것(북마크는 기록 지우기 대상이 아니라 계속 남음).
- 트렌드 ‘내 취향’ 주제어(`mineTopics`)도 같은 북마크 단어를 씀.
‘daum카페’ 같은 단어는 제목 단어에서 뽑힌 것으로 보임(예전에 담은 이미지 제목, 확정 아님).

## 18차에서 바뀐 것
- **뺀 단어**(`public/taste.js`): `mute/unmute/isMuted/muted`. 설정의 취향 태그 ✕ 는 점수를 지우면서 그 단어를 ‘뺀 단어’로 저장(‘덜 보기’ 칩은 점수만 지움). 뺀 단어는 학습·affinity·취향 순위에서 제외, 저장은 `taste` 값의 `mute` 필드(단어와 시각만). [모두 지우기]는 점수만 지우고 뺀 단어는 유지.
- **적용 위치**(`public/app.js`): `buildInterests` 는 뺀 단어가 든 활동을 관심사에서 제외(서명에 뺀 단어 목록 포함), `bmTopTags` 는 뺀 단어 제외(→ 홈 대체 칩·트렌드 내 취향).
- **홈 ⭐ 칩 ✕**: 칩 안 ✕ 로 바로 빼기 + [되돌리기] 토스트. 관심사 칩이면 맞춤 피드를 새로 짜고, 북마크 단어 칩이면 그 칩만 치움(`dropStar`).
- **설정 ‘뺀 단어’ 칸**(`#muteView`): 눌러서 다시 쓰기.
- **전체화면 보기**(`#vfs`·`#vfsx`·`enterFs/exitFs/fsReset`): 뷰어 버튼 줄에 [전체화면]. 켜면 `#viewer.fs` 로 제목·버튼·비슷한 이미지를 숨기고 이미지 영역을 화면 가득 채움(핀치·더블탭·좌우 넘기기 그대로, ‘원래 크기’ 버튼은 아래 가운데). 닫기: 오른쪽 위 ✕ / Esc / 뒤로 가기(전체화면용 기록 한 칸을 쌓아 두었다가 되돌림) / 뷰어를 닫으면 함께 해제. Fullscreen API 가 있는 브라우저(컴퓨터·아이패드)는 브라우저 화면까지 숨기고, 아이폰은 앱 화면 안에서만 채움.
- 서비스워커 v17, README 갱신.

## 배포 후 실제 기기에서 확인할 것
1. 홈 ⭐ ‘daum카페’(및 ‘신혼여행계획’)의 ✕ 를 눌러 빼고, 앱을 완전히 종료했다 다시 열어도 안 나오는지. 설정 ‘뺀 단어’ 칸에 들어 있는지.
2. 이전에 설정에서 지웠던 단어는 이미 ‘점수만 지운’ 상태라 한 번은 ⭐ ✕ 로 빼야 합니다(18차 이전 삭제 기록은 남아 있지 않음).
3. 뷰어 [전체화면]: 아이폰(Safari·홈 화면 앱)에서 이미지가 가득 차는지, 위쪽 ✕, 스와이프 뒤로 가기로 전체화면만 닫히는지, 핀치·더블탭·좌우 넘기기. 아이패드·맥에서 주소창까지 사라지는지.

## 알려진 한계·메모
- 뺀 단어는 정확히 같은 단어만 막습니다(‘다음카페’ 와 ‘daum카페’ 는 다른 단어). 비슷한 단어가 계속 나오면 같은 방법으로 추가로 빼면 됩니다.
- 뺀 단어가 든 활동은 관심사 묶음에서 통째로 제외됩니다(그 이미지의 다른 태그도 관심사에 반영되지 않음).
- 테스트 안정화: `tests/ui.test.mjs` 의 ‘private mode: learning paused’ 가 가끔 실패했음. 원인은 시간이 지나면 조금씩 변하는 취향 점수 숫자를 문자열로 비교한 것(1밀리초만 넘어가도 달라짐, 18차 변경과 무관한 기존 문제). 단어 이름만 비교하도록 고쳤고 연속 4회 통과(원본 코드 4회도 통과, 1회 실행 약 36초).
