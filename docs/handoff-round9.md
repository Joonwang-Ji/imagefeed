## 요청 (핀터레스트 벤치마킹 후)
톤·한 부분으로 찾기, 위키 조회수 기반 트렌드 교체, 북마크 분석·보드 추천, 취향 학습(기록 없이), ‘수업 모드’ → ‘비공개 모드’(글씨보다 아이콘). 10차: 20대 남녀가 좋아할 세련된 디자인 + 직관적인 UI.

## 9차에서 바뀐 것
- **트렌드** (`src/index.js`, `src/season.js`, `src/topics.js`): 응답이 `{ date, rising, season, items, dl }` 로 바뀜. 모든 사진 소스가 실패해도 200(주제 칩은 표시). `rising`=네이버 데이터랩(HUB `naverapihub.apigw.ntruss.com/search-trend/v1/search`, 5그룹씩 = 기준어 ‘사진’ + 후보 4개, 최근 7일 평균 ÷ 직전 21일 평균 − 1 ≥ 15% 이면 ‘rising’, 모자라면 검색량 큰 순 ‘hot’으로 6개까지), 12시간 캐시, 환경변수 `NAVER_TREND_BASE`(주소 바뀔 때)·`TREND_TOPICS=off`. `season`=날짜 계산(고정·음력표 2026~28·부활절·대림절·수능). 이미지 grp: `pop`(Pixabay·Unsplash), `pick`(커먼즈 우수 사진, 큰 원본은 1600px로 줄인 주소), `news`(위키 화제, 추천에서 분리).
- **톤·팔레트** (`public/color.js`): `tone()`(흑백·어두운·비비드·파스텔·밝은·차분한 + 따뜻한/차가운), `palette()`(대표 색 5개). 필터 패널 ‘톤’, 뷰어 색 점·톤 표시, [같은 톤만].
- **부분 검색** (`public/app.js`): 뷰어 [✂ 부분 검색] → 영역 그리기 → 잘라서 `/api/caption` → 그 말로 비슷한 이미지.
- **북마크**: 저장 때 `an`(톤·팔레트·색) 저장, 예전 북마크는 화면을 열 때 30개씩 뒤에서 분석, 톤·색 필터 칩, 보드별 [✨ 어울리는 이미지](보드 태그로 새 이미지 검색).
- **취향 학습** (`public/taste.js`): 설정에서 켜기(기본 꺼짐). 북마크 +3, 7초 시청 +1, 👍 +2, 👎 −3, 북마크 해제 −2. 반감기 45일, 태그 160개 상한, 선정 이미지·위키 화제 제목은 학습 제외. 반영은 메인 검색 결과 순서(최대 ±50%), 트렌드 정렬, 홈 ⭐ 칩, ⭐ 내 취향 버튼. 검색어·서버로는 보내지 않음. 설정에서 보기·지우기.
- **비공개 모드 🕶**: 헤더 아이콘. 켜면 북마크 탭·☆·보드·내 취향·⭐ 칩·👍👎·설정의 취향 칸이 숨고 학습·반영이 멈춤(데이터는 그대로). `LS priv` 로 기억.
- 서비스워커 v10(`/taste.js`), README 갱신.

- 자동 점검 9개 파일 모두 통과(색·톤·취향·시즌·관련도·피드·안전·서버·화면). 서버: 커먼즈 우수 사진 필터·순서·1600px·데이터랩 10묶음·성장률·캐시·권한 거절·키 없음·끄기. 화면: 비공개 모드·취향 학습/순서 조정·톤 판정·북마크 분석/필터·보드 추천·부분 검색·팔레트·👍.
