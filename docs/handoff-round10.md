# 이미지피드 — 10차 작업 결과와 11차 인계 (2026-10-27)

저장소: https://github.com/Joonwang-Ji/imagefeed (main). 변경 파일을 ZIP(imagefeed-round10.zip)으로 전달 → GitHub 웹에서 같은 경로로 덮어쓰기 업로드(자동 배포). 새 파일: `public/avoid.js`, `tests/avoid.test.mjs`, `docs/handoff-round10.md`.
키: Pixabay, Unsplash, 카카오, 네이버 등록됨. 원칙(바꾸지 말 것): 검색·조회 기록 저장 금지, 공포·잔혹 해제 불가, 선정성 기본 블러(설정에서 해제), 사용자는 본인과 소수 지인(성인), 기독교 세계관(다른 종교 주제는 추천에서 제외).

## 요청 (9차 확인 결과 + 피드백)
1. 할로윈·다른 종교 주제는 주제 칩 추천에서 제외(그 시기라도). 2. 부분 검색 영역을 직관적으로(옮기기·크기 조절) + 결과 보정(스피커를 골랐는데 가방만 나옴). 3. 설정의 취향 칩을 하나씩 지우기. 4. 트렌드에 네이버 추가. 5. 비슷한 이미지에 성경과 무관한 것 줄이기. 6. ‘다음부터 추천하지 마’ 학습(안전·취향 모두). 7. 아이폰에서 트렌드의 [새로고침] 버튼이 화면 밖으로 나감. 8. 원래 10차 계획: 20대 취향 디자인 + 직관적 UI, 9차 임시 스타일 정리.

## 10차에서 바뀐 것
- **종교 주제 제외** (`src/topics.js` `OFF_TOPIC`/`offTopic()`): 시즌 행사(`src/season.js`에서 할로윈·부처님오신날 삭제 + 필터), 데이터랩 ‘뜨는 주제’, 트렌드 사진(제목·태그 검사)에서 제외. 클라이언트 `CATS`의 ‘사찰 풍경’→‘고궁 풍경’, ‘전통 사원’→‘아치 회랑’, ‘별자리 지도’→‘천체 지도’.
- **네이버 트렌드** (`src/index.js` `hotPhotos`): 데이터랩에서 뜬 상위 3개 주제를 네이버 이미지로 검색해 주제당 14장, `grp: "hot"`, `topic` 이름표. 트렌드 탭에 ‘뜨는’ 분류 추가(추천에도 섞임). 취향 학습은 `hot` 제목에서 배우지 않음(`taste.js keysOf`).
- **새로고침 버튼**: `.trhead` = [분류 알약(flex:1, 좁으면 가로 스크롤)] + [아이콘 버튼]. Playwright 375px 캡처로 확인(버튼 오른쪽 끝 365/375, 가로 스크롤 없음, 다크·라이트).
- **부분 검색**(`public/app.js` `CR`·`crBounds`·`crSeg`): 상자가 이미지 영역 안에서만 이동·크기 조절, 최소 7%. 모서리 손잡이 4개(손가락 32px 판정). 빈 곳을 끌면 새로 그리기도 유지. 후보 검색어는 선택 부분 AI 설명 조각만(`simCandidates(..., crop=true)`), 보정 UI `#vcw`(단어 칩 토글, 직접 입력, `simRetry`). **버그 수정**: 하단 [이 부분으로 찾기] 버튼이 뷰어 확대 처리(wrap)의 포인터 캡처에 가로채여 크롬에서 안 눌리던 문제(`.vcbar` pointerdown에서 stopPropagation).
- **취향 칩 삭제**: `Taste.forget(kind, k)`; 칩은 `.tchip`(✕).
- **추천 안 함**(`public/avoid.js`, app.js `hideItem`·`refreshAvoidCards`·`applyAvoid`): pref(관심 없어요)/bad(보기 불편해요). 숨긴 키는 `Feed.merge`·`view()`에서 제외, 판정 1=점수×0.3, 2=`it.adult/ai/avoidBlur`로 블러(`.card.avoid`는 `body.noblur` 와 무관하게 항상 블러). 트렌드에도 적용. 북마크(`fromBm`)는 대상 아님. 설정에 ‘추천 안 함’ 칸(숨긴 장수·태그 칩·모두 지우기). 비공개 모드/취향 학습 여부와 무관하게 동작(안전 기능).
- **비슷한 이미지**: `fold:false` 제거 → 구체적 검색어에서 약한 결과는 [관련도 낮은 결과 보기] 뒤로.
- **디자인**(`public/index.html`, `public/style.css` 전면 교체): SVG 아이콘(`<symbol>`), 상단 = 검색 한 줄 + 도구 한 줄, 하단 탭바(피드·트렌드·북마크), 뷰어 동작 버튼 아이콘 격자, 보라→분홍 포인트 + 다크/라이트, 9차 임시 스타일 삭제. 모든 기존 `id` 유지.
- 서비스워커 v11(`/avoid.js` 추가). README 갱신.

## 검증
- 자동 점검 10개 파일 통과(color·feed·relevance·safety·season·server·taste·tone·avoid·ui). 새 점검: 종교 주제 필터(서버·시즌·홈 칩), 네이버 hot 이미지, 상자 이동/크기/경계/최소/새로 그리기, 보정 칩·직접 입력·후보 제한, 취향 칩 삭제, 숨김·블러 판정·설정 되돌리기. 변형 검사로 핵심 3곳(후보 제한·최소 크기·숨김 제외) 확인.
- 실제 브라우저(Chromium, 375px, 모의 API) 캡처: 홈·트렌드·뜨는·피드·뷰어·부분 검색·보정 칩·추천 안 함 시트·설정(다크/라이트).
- **실기기·실서버 미확인**: ① 네이버 이미지 ‘뜨는’ 탭(키·데이터랩 이용 신청 필요) ② 아이폰 사파리에서 부분 검색 상자 손잡이 터치 감각 ③ AI 설명 품질(스피커 사례) ④ 추천 안 함 판정 기준값(`avoid.js` 상단 상수) ⑤ 디자인 취향 ⑥ 보드 ‘어울리는 이미지’(9차부터 사용자가 아직 못 봄).
